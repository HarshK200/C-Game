# My 2D pixel art C++ game

This is a Game NOT! a game engine.
Code is sperated in layers inspired by Handmade hero code.


To run this in debug mode you must have a D3D11 Debug SDK installed,
you can read about how to install it here:
"https://learn.microsoft.com/en-us/windows/ai/directml/dml-debug-layer#installing-the-directml-and-direct3d-12-debug-layers-system-component"
or just run the following command mentioned in the above link:
```cmd
Add-WindowsCapability -Online -Name "Tools.Graphics.DirectX~~~~0.0.1.0"
```
